Project Description: 3D Object Detection Using Stereo Vision and YOLO¶

Summary:¶

This project uses a stereo image pair and the YOLO object detection model (v5 or v8) to estimate the 3D coordinates of detected objects. Objects are first detected in both the left and right images using YOLO. Matching objects across views are identified based on class label and spatial proximity. Then, depth is estimated via disparity between the x-coordinates of matched detections. Using camera intrinsics (focal length and baseline), the 3D position (X, Y, Z) of each object is computed. Finally, the results are visualized in a 3D scatter plot showing the real-world spatial layout of the detected objects.

# 5. Match objects between left and right images, here's how:
#    Write a line to initialize an empty list to store matched objects, call this matched_objects
matched_objects = []

# Start a for loop over all bounding boxes from the left image:
for i in range(len(boxes_left)):
# Inside the loop, assign the ith bounding box and label from the left image into box_l and label_l
    box_l = boxes_left[i]
    label_l = labels_left[i]
#### Begin a nested for loop to go over all bounding boxes from the right image:
    for j in range(len(boxes_right)):
#### Inside the nested loop, assign the jth bounding box and label from the right image to box_r and label_r
        box_r = boxes_right[j]
        label_r = labels_right[j]
#### Write an if condition to check whether the labels match:
        if label_l == label_r:
#### Inside this if block, compute the center x and y of the left bounding box:  x_left = (box_l[0] + box_l[2]) / 2
####                                                                             y_left = (box_l[1] + box_l[3]) / 2 #similar for right
            x_left = (box_l[0] + box_l[2]) / 2
            y_left = (box_l[1] + box_l[3]) / 2
######### Write an if condition (this is a nested if) to check if the two centers are within allowed thresholds
            if abs(x_left - box_r[0]) <= max_x_diff and abs(y_left - box_r[1]) <= max_y_diff:
######### Inside this block, calculate the disparity
                disparity = box_r[0] - box_l[2]
################## Add an if block to ignore cases where disparity is 0:
                if disparity != 0:
################## Inside this block, define the stereo camera parameters: focal_length and baseline (take this from Lab08) and calulate depth_z
                  focal_length = 718.856
                  baseline = 0.54
                  depth_z = baseline * focal_length / disparity
################## The rest of the block is given to you
                    # Estimate 3D coordinates (assuming optical center at (cx, cy))
                  cx = left_img.shape[1] / 2
                  cy = left_img.shape[0] / 2

                  x_real = (x_left - cx) * depth_z / focal_length
                  y_real = (y_left - cy) * depth_z / focal_length

                  # Store only numeric data (coordinates and depth)
                  matched_objects.append((float(x_real), float(y_real), float(depth_z)))

                  # Print 3D coordinates for detected object
                  print(f"Detected {model.names[int(label_l)]} at (X: {x_real}, Y: {y_real}, Z: {depth_z}) meters")

# Plot matched objects in 3D if there are any
if len(matched_objects) > 0:
    # Convert matched_objects to numpy array for easy plotting
    objects = np.array(matched_objects)

    # Ensure objects is 2D before plotting
    if objects.ndim == 2:
        # Plot in 3D
        fig = plt.figure(figsize=(10, 7))
        ax = fig.add_subplot(111, projection='3d')

        # Plot only numeric data (coordinates and depth)
        ax.scatter(objects[:, 0], objects[:, 1], objects[:, 2], c='r', marker='o')

        # Labels
        ax.set_xlabel('X Coordinate (meters)')
        ax.set_ylabel('Y Coordinate (meters)')
        ax.set_zlabel('Z Coordinate (meters)')
        ax.set_title('3D Object Detection from Stereo Images')

        plt.show()
else:
    print("No matched objects found.")
